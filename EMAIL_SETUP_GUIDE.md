# Email Setup Guide

The application uses NodeMailer with a **Brevo** SMTP server (formerly Sendinblue) to send automated reminders and follow-up emails regarding pending points. 

## Configuration Details

The system uses Brevo because it is highly reliable for transactional application emails and easily bypasses strict corporate firewalls.

### Method 1: Using the Admin Portal (Recommended)

The easiest way to update the system email is through the Admin Dashboard.

1. Log in to the application as an **Admin**.
2. Go to **Settings** from the sidebar.
3. Scroll down to the **System Email Configuration** section.
4. Enter your **Brevo Login Email** (e.g., `yourname@smtp-brevo.com`).
5. Enter your **Brevo SMTP Password** (this is a long key generated by Brevo) into the password field.
6. Click **Save Configuration**.

*Behind the scenes, the Admin Portal automatically updates the `.env` file on the server and live-reloads the email service without requiring a server restart.*

### Method 2: Manual `.env` Configuration

If you prefer to configure it manually, open the `.env` file located in the `server` folder (`server/.env`) and add or update the following block:

```env
# Email Configuration
GMAIL_USER=your_brevo_login_email
GMAIL_APP_PASSWORD=your_brevo_smtp_password
```
*(Note: the environment variables retain the `GMAIL_` prefix for legacy compatibility, but they power the Brevo integration).*

After updating the `.env` file manually, you must restart the backend server for the changes to take effect.

## Adding Recipients

To determine *who* receives these emails:
1. Go to the Admin **Settings** page.
2. Under **Email Recipients**, click **Add Recipient**.
3. Fill in the Department, Contact Name, and Email Address.
4. Check the boxes for:
   - **Receives Reminder Email**: Triggered manually when an Admin rejects pending points.
   - **Receives Follow-Up Email**: Triggered automatically by the system cron job if points are open 48 hours after the `received_date`.
5. Click Save.

## How to get Brevo Credentials

1. Go to https://app.brevo.com/account/register and sign up for a free account.
2. Once logged in, click your name at the top right and select "SMTP & API".
3. Under the "SMTP" tab, you will find your Login Email and SMTP Password.

## Troubleshooting

- **"Invalid Login" error**: Verify that the email and password are correct. Make sure you are using your Brevo SMTP key, NOT your standard account login password.
- **Emails are not sending**: Ensure the backend server has internet access, and port 587 is not blocked by your firewall. Check the Admin Portal's **Email Logs** page for specific error messages.
